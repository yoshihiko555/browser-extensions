# Bookmark Sorter

ブックマークバーの各フォルダを、閲覧履歴の訪問回数が多い順に並び替える拡張機能。

## 機能

- ポップアップを開くと、並び替えた場合に位置が変わるフォルダと件数を表示する（この時点では何も変えない）
- 「並び替える」で反映する
- 「直前に戻す」で最後の 1 回分を、「初回の前に戻す」で最初に並び替える前の並びに戻す

## 並べ方の規則

- ブックマークバー直下の並びは変えない。並び替えるのは各フォルダの中だけ
- フォルダの中は、サブフォルダを今の順で先頭に置き、その後にブックマークを訪問回数の多い順に並べる
- 訪問回数は閲覧履歴から、サイト（ホスト単位。先頭の `www.` は除き、ポートは区別する）ごとに合算する
- 同数・未訪問・`javascript:` などの特殊な URL は、今の順を保つ

## 注意

- 数えるのは「そのサイトを開いた回数」で、ブックマークから開いた回数ではない
- リダイレクト先は追わない。移転したサイトは、ブックマークの URL を新しいものに更新しないと回数が少なく数えられる
- 戻すための記録は `chrome.storage.local` に保存する。拡張を削除すると消える
- 閲覧履歴とブックマークは外部に送らない（通信しない）

## インストール

1. ブラウザで `chrome://extensions/` を開く（Dia は `dia://extensions`）
2. 「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」で `bookmark-sorter/extension/` を選択する

## 使い方

1. ツールバーの Bookmark Sorter アイコンをクリックする
2. 表示された件数とフォルダ一覧を確認する
3. 「並び替える」をクリックする

## テスト

- 単体テスト: `node --test test/sort.test.mjs`
- Dia での通しテスト（検証用プロファイルで起動してから実行）:

  ```sh
  open -na Dia --args --user-data-dir=<別ディレクトリ> --remote-debugging-port=9226 \
    --load-extension="$PWD/extension"
  node test/dia_e2e.mjs 9226
  ```
