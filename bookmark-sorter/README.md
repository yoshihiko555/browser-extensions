# Bookmark Sorter

ブックマークバーの各フォルダを、閲覧履歴の訪問回数が多い順に並び替える拡張機能。
構成ファイルに沿ってフォルダ構成を組み直す機能もある。

## 機能

- ポップアップを開くと、並び替えた場合に位置が変わるフォルダと件数を表示する（この時点では何も変えない）
- 「並び替える」で反映する
- 「直前に戻す」で最後の 1 回分を、「初回の前に戻す」で最初に並び替える前の並びに戻す
- 「構成を反映…」で、構成ファイルに沿ってフォルダの作成・移動・名前変更とブックマークの移動を行う（下記）

## 並べ方の規則

- ブックマークバー直下の並びは変えない。並び替えるのは各フォルダの中だけ
- フォルダの中は、サブフォルダを今の順で先頭に置き、その後にブックマークを訪問回数の多い順に並べる
- 訪問回数は閲覧履歴から、サイト（ホスト単位。先頭の `www.` は除き、ポートは区別する）ごとに合算する
- 同数・未訪問・`javascript:` などの特殊な URL は、今の順を保つ

## 注意

- 数えるのは「そのサイトを開いた回数」で、ブックマークから開いた回数ではない
- リダイレクト先は追わない。移転したサイトは、ブックマークの URL を新しいものに更新しないと回数が少なく数えられる
- 戻すための記録は `chrome.storage.local` に保存する。拡張を削除すると消える
- 閲覧履歴とブックマークは外部に送らない（通信しない）

## 構成を反映

ポップアップの「構成を反映…」で専用のタブが開く。構成ファイル（JSON）を選ぶと反映後のフォルダ構成と件数が表示され、「反映する」で反映する。

- 何も削除しない。既存のフォルダは移動と名前変更だけで、ID はそのまま残る
- 書き込む前に今のブックマークと照合し、ID・URL・フォルダ名が 1 件でも食い違えば何も変更しない
- 反映済みの操作は飛ばすので、途中で止まっても再実行で続きから反映できる
- 「構成を元に戻す」で、最初に反映する前のフォルダ構成と並びに戻す。このとき作ったフォルダは空なら消す
- 最初に反映するとき、それまでの並び替えの「戻す」の記録を退避する。反映後の並び替えは新たに記録され、「構成を元に戻す」と退避した記録が復元される
- フォルダの中の並びは変えない。反映後に「並び替える」を押す

構成ファイルの形式（パスはブックマークバーからの `/` 区切り）:

```json
{
  "format": "bookmark-sorter/structure@1",
  "createFolders": ["Design", "Design/Interior"],
  "folders": [{ "id": "<フォルダ ID>", "title": "Idea", "to": "Design", "rename": "Inspiration" }],
  "moves": [{ "id": "<ブックマーク ID>", "url": "<今の URL>", "to": "Design/Interior" }],
  "folderOrder": { "": ["Me", "Design", "News"], "Design": ["Inspiration", "Interior"] }
}
```

- `folders` の `to` を省くと名前変更だけになる
- `folderOrder` は親フォルダごとのサブフォルダの順。書いていないフォルダは今の順で後ろに並び、ブックマークの位置は変えない

構成ファイルには実際のブックマークの URL が入るので、リポジトリに置かない。

## インストール

1. ブラウザで `chrome://extensions/` を開く（Dia は `dia://extensions`）
2. 「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」で `bookmark-sorter/extension/` を選択する

## 使い方

1. ツールバーの Bookmark Sorter アイコンをクリックする
2. 表示された件数とフォルダ一覧を確認する
3. 「並び替える」をクリックする

## テスト

- 単体テスト: `node --test test/sort.test.mjs test/restructure.test.mjs`
- Dia での通しテスト（検証用プロファイルで起動してから実行）:

  ```sh
  open -na Dia --args --user-data-dir=<別ディレクトリ> --remote-debugging-port=9226 \
    --load-extension="$PWD/extension"
  node test/dia_e2e.mjs 9226
  node test/dia_structure_e2e.mjs 9226
  ```

  `dia_structure_e2e.mjs` は実行時にブックマークバーを空にするので、普段のプロファイルでは実行しない。
